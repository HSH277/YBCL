# 异步请求工具 — AI 提问内容记录

## 第一轮：需求确认

**提问:**
> 为电商前端添加异步请求功能，封装一个独立的请求工具（如 request.js），
> 对接API接口或Mock数据，实现商品列表的分页查询和分类筛选

**AI 回复摘要:**
- 设计 request.js 模块结构（IIFE + 全局暴露）
- 基于 XMLHttpRequest + Promise 封装
- 设计拦截器机制（请求拦截/响应拦截）
- 实现 Mock 数据自动切换
- 分页查询 + 分类筛选方案

---

## 第二轮：代码生成

**AI 执行内容:**

1. **创建 `js/request.js`** — 独立请求工具
   - XMLHttpRequest + Promise 封装
   - 请求/响应拦截器队列
   - 自动携带 Token
   - 401 跳转登录
   - 后端不可用时自动切换 Mock

2. **创建 `js/mock.js`** — Mock 数据模块
   - 30 条商品数据（4 个分类）
   - 分页查询逻辑（筛选 + 分页）
   - 分类查询
   - 模拟网络延迟（200-500ms）

3. **改造 `js/products.js`** — 分页 + 筛选
   - 分页状态管理（currentPage）
   - 每页发送一次请求
   - 搜索/筛选时重置页码
   - 自动适配 Mock 和真实 API

4. **更新 `index.html`** — 引入脚本 + 分页容器
   - 引入 request.js、mock.js
   - 添加分页控件容器
   - Mock 模式提示横幅

5. **创建文档**
   - `docs/4-异步请求工具实现思路.md`
   - `docs/5-异步请求AI提问记录.md`
